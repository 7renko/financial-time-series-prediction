# Прогнозирование финансового временного ряда

Проект по анализу финансовых временных рядов с помощью нейронных сетей.

В рамках проекта решаются две задачи:

- прогнозирование нижних и верхних точек разворота цены;
- прогнозирование обращенного медленного стохастического осциллятора `inv_slow_k`.

Для определения точек разворота используются модели бинарной классификации, а для прогнозирования `inv_slow_k` - регрессионные нейронные сети.

## Описание проекта

В качестве исходных данных используются временные ряды торговых цен акций Сбербанка. 

На основе исходного ценового ряда формируются признаки, учитывающие изменение цены на разных временных интервалах. Затем обучаются несколько полносвязных нейронных сетей различной глубины и размера.

Основные этапы:

- предобработка финансового временного ряда;
- формирование признаков на основе разностей цен с различными временными лагами;
- нормализация входных признаков;
- формирование целевых переменных;
- обучение моделей для прогнозирования локальных минимумов и максимумов;
- обучение регрессионных моделей для прогнозирования `inv_slow_k`;
- сравнение различных архитектур нейронных сетей;
- оценка качества моделей на обучающей, тестовой и отложенной выборках.

## Прогнозирование точек разворота

Для определения точек разворота обучаются две отдельные модели:

- модель для прогнозирования локальных минимумов;
- модель для прогнозирования локальных максимумов.

Нижняя точка разворота определяется как момент времени, в котором текущая цена ниже трех предыдущих и десяти последующих значений.

Верхняя точка разворота определяется аналогично: текущая цена должна быть выше трех предыдущих и десяти последующих значений.

Задача решается как бинарная классификация.

## Прогнозирование обращенного Slow %K

Для второй части проекта используется медленный стохастический осциллятор.

Целевой переменной является его обращенное значение:

```text
inv_slow_k = 100 - slow_k
```

Значения `inv_slow_k` находятся в диапазоне от 0 до 100.

В отличие от задачи определения точек разворота, данная задача решается как регрессия.

## Признаки

Входные признаки строятся на основе разностей цен с различными временными лагами.

Использование нескольких временных интервалов позволяет учитывать как краткосрочные изменения цены, так и более долгосрочную динамику временного ряда.

Перед обучением входные признаки нормализуются.

## Модели

В проекте сравниваются полносвязные нейронные сети прямого распространения различной глубины.

Используемые архитектуры:

```text
32-16
64-32
32-16-8
64-32-16
```

Для задач классификации и регрессии сравнивается качество трехслойных и четырехслойных моделей.

## Результаты

Для прогнозирования `inv_slow_k` наилучший результат показала сеть:

```text
64-32-16
```

Результаты модели:

```text
Validation correlation: 0.7307
Test correlation:       0.6693
```

Сеть `64-32` показала близкий результат:

```text
Test correlation: 0.6662
```

Таким образом, увеличение глубины сети дало небольшое улучшение качества, однако существенного прироста по сравнению с более простой архитектурой получено не было.

Для моделей прогнозирования точек разворота качество оказалось ниже.

Это связано с тем, что локальные минимумы и максимумы являются редкими событиями, поэтому задача характеризуется дисбалансом классов. Дополнительную сложность создает высокая шумность финансового временного ряда.

## Визуализация результатов

Для регрессионных моделей строится сравнение истинных и предсказанных значений `inv_slow_k` на:

- обучающей выборке;
- тестовой выборке;
- отложенной выборке.

Модели хорошо воспроизводят общую динамику индикатора, однако сглаживают резкие изменения и хуже предсказывают экстремальные значения.
